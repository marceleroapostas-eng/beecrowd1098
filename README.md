# Beecrowd 1098 - Sequência IJ 4

## Descrição
Programa desenvolvido em Java para imprimir a sequência de valores das variáveis I e J, conforme solicitado pelo Beecrowd.

## Linguagem
Java

## Entrada
O programa não possui entrada de dados.

## Saída
Imprime os valores de I, de 0 até 2, aumentando de 0,2 em 0,2, e os valores de J, conforme a sequência especificada no enunciado.
